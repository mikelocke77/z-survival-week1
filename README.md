# Keep Your Head — Survival Manual (Week One)

A ready-to-deploy Next.js app with Tailwind + Framer Motion and your CRT-styled survival manual.
- Journals auto-save (localStorage)
- Scripture modal (KJV inline, NIV/HCSB open on BibleGateway)
- Badges + streaks
- Swipe navigation
- Splash/title screen

## Quick start
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Deploy to Vercel
1. Push this folder to GitHub.
2. Go to https://vercel.com/new and import the repo.
3. Click **Deploy**.

## Notes
- NIV/HCSB text opens externally to respect licensing.
- To add Week 2+, copy the `CONTENT` pattern and extend with more pages.
